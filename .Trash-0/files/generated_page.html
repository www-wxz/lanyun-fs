探索：圆的周长与面积

通过可交互的动画理解 C=πD 与 A=πr²

主题：图形与几何 · 二级：图形 的认识与测量 · 年级：5～6年级

半径 r: 3.00 cm
直径 D: 6.00 cm
周长 C: 18.85 cm
面积 A: 28.27 cm²


教学提示与活动说明

基本实验活动：探索圆的周长和面积计算公式。

学习目标

  • 理解并能操控圆的基本要素：半径 r、直径 D、周长 C、面积 A
  • 通过实验观察并推导 C 与 D 的关系（C = πD）
  • 通过扇形重排直观证明 A = πr² 并能用公式进行计算
  • 培养动手实验、记录与得出结论的习惯

评估建议

  1. 记录至少 3 次不同半径下的 C/D 并计算平均值，判断是否接近 π
  2. 使用扇形重排观察不同切分数下近似矩形的差异并解释
  3. 提交一次半径值及预测面积，比较实际计算值并写出 1-2 行观察结论

步骤导航

  1. 准备：在画布上观察主圆，确认当前半径 r（可通过滑块或拖拽把手调整）。
  2. 周长探索：记录多个不同 r 下的周长 C 与直径 D，计算 C/D 的比值并记录结果。
  3. 扇形分割：打开“显示扇形分割”，增加切分数，观察并记录扇形重排后的近似矩形长度与高度。
  4. 面积验证：根据重排观察，讨论并写出 A = πr² 的直观解释；使用公式计算并比对实际数值。
  5. 总结与提交：完成评估建议中的记录表，并写出 1-2 行观察结论。
